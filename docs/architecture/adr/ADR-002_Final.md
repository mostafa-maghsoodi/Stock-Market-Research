# ADR-002 — Stage-scoped outcome-free Screen Specification

## ADR ID

`ADR-002`

## Title

Stage-scoped outcome-free Screen Specification

## Status

FINAL — approval state is external to these bytes. This document does not
self-attest approval. Governing effect is determined only by the applicable
external Approval Record identity and human approval process.

## Decision

A separate stage-scoped outcome-free Screen Specification is authorized for:

`historical universe → PIT facts → accounting semantics → Proxy Registry → ranking configuration → deterministic ranked candidate process`

It is not a BUY list, portfolio specification, or outcome-evaluation
specification.

## Scope

The decision is limited to the separate outcome-free screen stage and the
stated deterministic process.

## What this decision does NOT authorize

It does not select a vendor, threshold, formula, date, candidate cutoff, or
portfolio assumption; authorize realized-outcome use; or create a BUY list.

Architecture v3.2 incorporates this separate stage as a subordinate contract
boundary.
